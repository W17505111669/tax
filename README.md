# 税务智能审查平台（双智能体参赛作品）

全国税务师行业 AI 赋能涉税专业服务技能竞赛参赛作品。一个共享技术底座承载两个独立业务智能体：

- **智研税审**——研发费用加计扣除专项审查
- **土增智填**——合同发票账簿智能核验填表

技术路线：Pi Agent SDK（`@earendil-works/pi-coding-agent@0.87.1`，已锁定）+ TypeScript + React + Vite + Tailwind + Fastify + SQLite（`node:sqlite`）。

## 快速开始

```bash
pnpm install
cp .env.example .env        # 按需修改模型端点
pnpm dev                    # 同时启动 API(8787) 与前端(5173)
```

打开 `http://127.0.0.1:5173/`，选择智能体，输入任务或使用示例任务，点击「创建并执行」，即可在工作台实时查看 Agent 执行过程。

端口以终端实际输出为准：5173 被别的项目占用时 Vite 会自动往后找一个空闲端口，这时浏览器里的旧地址打开的是别的应用。要固定端口就在 `.env`（或 `apps/web/.env`，后者优先）里写 `WEB_PORT=5174`；`/api` 代理始终指向 `API_PORT`，改端口不影响联调，录屏分镜表里的深链也会跟随 `WEB_PORT` 生成。

## 关键设计

- **双 Agent 真正独立**：各自独立的系统提示词、工具集与会话；Pi 内置 `read/bash/edit/write` 一律禁用（`noTools: "builtin"`），业务 Agent 不具备任何系统操作能力。
- **金额不由大模型计算**：限额、汇总、差异全部由 TypeScript 工具以整数分确定性计算，模型只负责解释与组织结果。
- **状态以真实事件为准**：任务状态由持久化事件与执行结果决定，不依据模型文字判断；SSE 事件先落库再推送，前端可回放。
- **模型端点可替换**：`.env` 中配置 `TAXAI_BASE_URL / TAXAI_API / TAXAI_MODEL`，默认指向本机 OpenAI 兼容网关，可切换为任意兼容服务。
- **配置隔离**：Pi 的 `agentDir` 指向项目内 `data/agent-home`，不读取也不污染用户全局 `~/.pi`。
- **对话式工作台**：前端对齐法律/财税 AI 产品视觉语言——窄图标栏 + 可折叠会话侧栏、居中对话列、可折叠工具调用步骤（入参/返回）、引用来源胶囊与复制/重新生成操作行、底部发光输入框、大数字首页与任务状态条形图、底部品牌栏；侧边阅读器按「引用文件 / 文件生成」分组页签管理网页、任务资料与产物预览，加载时为点阵动画。

## 已知不足

数字不好看也如实列出。以下口径与平台看板、交付自检、`docs/testing/phase0-verification.md` 同源，不填占位数字。

- **弱证据引用 23 条，按现行判据待处置 0 条**：全部是百科词条与门户首页一类没有具体文件内容的页面，例如「研发_百度百科」「国家政务服务平台」。其中 15 条已在结论中写明「仅作背景参考，不作为政策依据」，8 条只出现在联网检索留存里、从未进入结论正文（不是这份交付材料的依据，也没处补标注）——两类都不再催人替换，看板缺口清单因此为空。此前两次批量复查各 12 条、matched 均为 0：这类页面结构上找不到「同主题的官方原文」可替换，复查通道对它们无效，这也是把这两类判为「不必催办」的依据。交付自检另按判据点名与业务主题无关的引用，建议直接从结论中删掉。
- **底稿比对累计 5 项：一致 3 + 填错 2，一致率 60% · 覆盖率 100%**（最近一次 66.67% / 100%）。一致率只看两边都有的项，回答「填得对不对」；覆盖率回答「人工底稿有的项自动填到了多少」。填错的 2 项经查是案例里预埋的演示差异，不是填列逻辑错。覆盖率此前一度显示 36.84%，那是把「填列产物 vs 它自己的原始模板」这类比对里新增的单元格记成了覆盖缺口——等于把「填了多少」当成「漏了多少」；现已按产物溯源单独统计，不再进一致率与覆盖率。
- **通用搜索引擎对中文长查询已退化**：Bing 忽略 `site:` 运算符、长查询只命中「国家」二字就返回百科词条，百度持续安全验证。政策文号因此改走国家税务总局政策法规库的定向检索接口，通用检索只作兜底；未命中也不写成「库内未收录」，只说「检索接口未返回该字号」。
- **三处纯视觉细节待人工确认**：平台台账两列欠账（第 7 列「待复查」、第 12 列「证据力弱」）的琥珀色高亮落点、引用胶囊的「官方来源」标签、看板 KPI 卡在窄屏下是否折行。自动化门禁覆盖口径与数值，覆盖不到像素级排版。
